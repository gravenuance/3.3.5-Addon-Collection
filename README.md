## Addon bundle

Ace3 and `!!!ClassicAPI` are required for many of these addons.

Most have been **re-written**, some are new, and several have gained significant new features.

---

### Included addons

- **!!!Zoom!!!**  
  Re-written to handle garbage collection more cleanly.

- **AddonList**  
  Backported version of Blizzard's addon management UI, with further improvements on top of the port.

- **BlizzMove**  
  Re-written to avoid random bugs and improve overall stability.

- **BlueRedRange**  
  New addon that functions similarly to `TullaRange`.

- **CombatLogFix**  
  Re-written and now includes an additional combat log fix.

- **CompactNameplates**  
  Re-written with many new configuration options and features.

- **CompactRaidFrame**  
  Blizzard's modern compact raid frames, backported to this client. Required by `CompactRaidFrameDispel` and `FrameSort`.

- **Doom_CooldownPulse**  
  New behavior: disables the button when the effect is not active.

- **FrameSort**  
  Backported version, with further improvements on top of the port. Pins the player frame to a fixed position (top/middle/bottom) in party/raid frames.

- **OmniCC**  
  Includes fixes for long-standing issues, such as timers not resetting correctly on `ZONE_CHANGE`.

- **OneBag3**  
  Re-written for better performance and maintainability.

- **RAF**  
  New addon with simple arena frames made to look like raid frames.

- **RetailUI**  
  Re-written and cleaned up, with multiple bugs fixed.

- **SimpleCombatLogger**  
  Backported for compatibility with this client.

- **SnowfallKeyPress**  
  Re-written and slightly adjusted to feel more responsive.
